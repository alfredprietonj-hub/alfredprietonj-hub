## 🚀 What I've Built

### [LearnFlow](https://learnflow.makerlabssv.com/) — AI-powered learning platform
An interactive e-learning platform that teaches technical subjects through structured visual paths, quizzes, and an AI tutor.

- **Courses:** Python, C++, CUDA, GPU Architecture, AI Essentials, and Robotics
- **Features:** AI tutoring, progress tracking, quiz engine, tiered anonymous/authenticated access
- **Stack:** Next.js 14 · React · TypeScript · Tailwind CSS · Supabase · Google OAuth · DeepSeek API · Vercel

Built solo — from schema design and row-level security policies through OAuth flows, content rendering, and CI/CD deployment.

### [SQLTranslate](https://sqltranslate.makerlabssv.com/) — SQL dialect converter
Converts SQL queries between MySQL, PostgreSQL, SQLite, SQL Server, and Oracle. Built to remove a recurring friction point when moving between database environments.

### AgentReady — *in development*
A scanner that evaluates how readable a website is to AI agents and AI search, returning a readiness score plus actionable fixes. Currently in build: async job pipeline, rate-limited crawling, and a scoring engine.

## 💡 How I Think About Building

Twenty years of running complex hardware programs taught me that shipping is a discipline, not an event — you define the scope, map the dependencies, find the critical path, and remove blockers before they compound. I apply the same approach to software: scope tightly, build iteratively, deploy early, and let real usage drive the next decision.

I'm especially interested in where AI meets the physical and technical world — engineering data, hardware systems, and tools that make hard technical subjects genuinely learnable.
